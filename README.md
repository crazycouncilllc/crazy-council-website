# Crazy Council LLC Website

Deploy-ready Vite + React project for Cloudflare Pages.

## Cloudflare Pages settings

- Framework preset: Vite
- Build command: npm run build
- Build output directory: dist
- Root directory: /

## Contact form

The form falls back to mailto if no key is set. To route submissions to your Microsoft 365 inbox, add this environment variable in Cloudflare Pages:

VITE_WEB3FORMS_ACCESS_KEY=your_web3forms_key
